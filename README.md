# 🔍 OSINT Toolkit

A modular, command-line OSINT & Reconnaissance suite written in Python.

## 🚀 Features

* **15+ Specialized Modules:** From Domain & Network scanning to Public Data Breach checks, IP Geolocation, Crypto Wallet lookups, and more.
* **Clean CLI Interface:** Modern terminal layout with structured tables, ASCII art, and smooth UX.
* **Modular Architecture:** Easily scalable – each tool runs from its own independent module file.
* **OSINT Framework Integration:** Quick access to the official OSINT Framework directly from the menu.
